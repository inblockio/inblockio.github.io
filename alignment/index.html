How the five fit together.

  1. 01 Proof of Control asks what evidence an AI system must produce so that others can check it.
  2. 02 The EU AI Act asks organisations for records and oversight that such evidence can support.
  3. 03 Internet and cryptography standards are the building blocks both rest on: hashing, signatures, timestamps, transparency logs.
  4. 04 C2PA and Sigstore solve neighbouring problems, for media and for software, with different trust models.
  5. 05 git and CRDTs show Aqua underneath tools people already use.
